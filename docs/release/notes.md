# Her World 0.6.0 发布说明

0.6.0 支持从**已完成迁移的 0.5.0**升级。guest 和 Room 电视仍能回复，回复中的控制字段不会写入伙伴的共享情绪。设置页继续从已绑定的 Repo 读取日记、相册和现有外观，从钱包读取未结请求，断线后可凭原号查证。当前随包工具提供安装、搬家、配置修复与离线备份。

## 从 0.5.0 升级

确认使用的是已经完成存储迁移的 0.5.0。仍在 0.4.0 的安装先按 [v0.5.0 历史钱包迁移说明](https://github.com/hyyino7/her-world/blob/v0.5.0/docs/development.md#console-wallet-migration) 完成升级并核对存储。0.6.0 的操作入口见[安装与更新](../github-updates.md#dsh-installation-and-updates)。

## 隔离验收与换包回退

1. 在已迁移的 0.5.0 隔离环境打开 **Her World → 版本**，点 **更新**安装 0.6.0。确认插件激活、设置页和外观编辑器可开、根插件与 Core 描述正确显示。
2. 保存一项设置并重启读回，打开日记相册和钱包待办。在设置里投喂，核对身体状态和事实确认，再从另一会话召回，重启后再次召回。核对 Room 和桌宠活动刷新与语音取消。已有渠道配置时，用实机核对收件去重。记录设置、Bank 观察和钱包请求的读回状态，留作回退对照。
3. 在同一隔离环境从 **版本**页换回 0.5.0，沿用该 Repo。核对第 2 步写入的设置、Bank 观察和钱包请求均可读，原钱包请求没有重复执行。
4. 主人确认以上通过后再更新日常机器。任一失败时保持日常安装在原版本。需要按备份恢复数据时，走[离线文件备份和同机恢复](../portability.md#offline-file-backup-and-same-machine-recovery)。

### 已知边界

关闭多只桌宠过程中换绑时，已交给上游的那一只可能在原工作区完成隐藏和保存。后续宠物受绑定校验保护。
