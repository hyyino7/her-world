# Her World 0.7.0 发布说明

0.7.0 新增用量账本：伙伴工作区里每一次可观察的模型调用记一行，只存时间、入口、预设、用途、结局和原始用量，不存内容。设置里新增「用量」分页，按天查看各入口、预设和用途的调用次数、未命中输入、缓存读写、输出和估算花费，并单列缺用量、无价格和记录失败的次数。渠道用量和 Life 每日预算仍按原来的方式统计。

## 从 0.6.0 升级

支持从 0.6.0 和已完成迁移的 0.5.0 升级，入口见[安装与更新](../github-updates.md#dsh-installation-and-updates)。账本在第一次模型调用时建立，位置是伙伴 Repo 的 `.chatpet/data/usage/ledger.sqlite`。账本写失败时聊天照常，用量页会显示记录失败的次数。写入和回退协议见[用量账本写入协议](../architecture.md#llm-storage-plan)。

## 隔离验收与换包回退

1. 在隔离环境从 **Her World → 版本**更新到 0.7.0。分别在 DSH 原生、桌面、Room 和已配置的渠道各聊一句，触发一次压缩，打开设置的「用量」分页，确认每类调用都有记录、归类正确。
2. 退出 DSH 再打开，确认用量页的记录和合计还在。
3. 需要回退时，从同一版本页换回 0.6.0。0.6.0 不读账本，账本文件和新增记录原样保留，重新升级后接着记。
4. 主人确认以上通过后再更新日常机器。需要按备份恢复数据时，走[离线文件备份和同机恢复](../portability.md#offline-file-backup-and-same-machine-recovery)。
