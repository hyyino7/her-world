# Her World 0.8.0 发布说明

0.8.0 把渠道用量和 Life 每日预算改成从用量账本计算，删掉各自的旧累计。

- **QQ／微信设置的用量行**：显示本伙伴经该渠道近 30 天（含今天）所有账号的调用次数、未命中输入、缓存读写、输出和估算花费。原来是当前账号的全期累计。
- **生活卡**：显示「今天 home 花费（账本）」，包括压缩和标题。无价格的调用单列次数，不计入金额；缺价项标注部分估算。
- **每日费用提醒**：金额取账本里当前 home 当天的全部调用。仍在 home 每出一条带用量的助手消息时检查，所以压缩把花费推过预算时，提醒在下一条助手消息出来时发出，当天最多一次。账本暂时读不了时跳过这次检查。
- **用量页**：去掉「旧统计对照」。

旧的渠道计数记录停写并保留，退回旧版时可以接着用。

## 从 0.7.0 升级

支持从 0.7.0、0.6.0 和已完成迁移的 0.5.0 升级，入口见[安装与更新](../github-updates.md#dsh-installation-and-updates)。从 0.7.0 升级时账本已有记录，预算和渠道读数直接接上。从更早版本升级时，当天升级前的花费不在账本里，当天预算金额会偏小。

## 隔离验收与换包回退

1. 在隔离环境从 **Her World → 版本**更新到 0.8.0。在 home 聊一句，打开生活卡确认「今天 home 花费」有数；把每日费用提醒设得比当前花费略高再聊一句，确认 home 里收到一次「额度用完」。
2. 在 QQ 或微信聊一句，打开连接页确认用量行是近 30 天合计，和用量页逐日相加一致。
3. 退出 DSH 再打开，确认读数还在，当天没有重复提醒。
4. 需要回退时，从同一版本页换回 0.7.0 或 0.6.0。旧版读得懂 0.8.0 写的花费和提醒标记，当天不会重复提醒；旧渠道计数从升级前的值接着加，缺 0.8.0 期间的调用。再升回 0.8.0 时金额按账本重算，退回 0.6.0 期间的花费不在账本里，金额会变小。详见[账本回退](../architecture.md#llm-rollback-plan)。
5. 主人确认以上通过后再更新日常机器。需要按备份恢复数据时，走[离线文件备份和同机恢复](../portability.md#offline-file-backup-and-same-machine-recovery)。恢复会把账本回卷到备份时刻，下一次检查按回卷后的账本重算，当天已提醒的不会再提醒。

### 已知边界

- 一天之内换了 home 时，预算只算新 home 的花费，提醒标记沿用。
- DSH rc.5 的 DeepSeek 适配器不报推理 token，账本里推理 token 显示「未报」，花费估算不受影响，见[宿主核实](../architecture.md#llm-host-verification)。
- 关闭多只桌宠时的换绑边界见[已知问题 12](../product.md#known-issue-12)。
