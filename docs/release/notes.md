# Her World 0.5.0

这一版调整了 Room、桌宠和语音的协作，也把设置页的钱包待办存进伙伴的钱包。**从 0.4.0 升级需要离线迁移，请先在隔离环境验收。**

## 你会看到的变化

- Room 和桌宠按同一份活动进度和情绪选择各自的素材，部分混合情绪下的待机表现会变。桌宠已经在吃饭时再点吃饭，只会播放，投喂只生效一次。
- 在紧凑聊天窗里，停止朗读、切换会话或隐藏窗口会取消对应的语音请求。
- 设置页的钱包操作遇到断线，重开页面或重启后可以凭原编号查证，并按页面提示重试。待办结清前，钱包会拦住新的写入操作。

## 从 0.4.0 升级、迁移和回退

新增 `0004-console-wallet`，把 Console（设置页）留在浏览器里的钱包待确认请求按原编号迁入持久存储，存储清单更新为 `core:3/living:4`。导入只登记待办，不会执行这些请求。

在隔离副本上按下面的顺序操作。完整命令和停写要求见 [Console 钱包迁移操作清单](https://github.com/hyyino7/her-world/blob/v0.5.0/docs/development.md#console-wallet-migration)。

1. **先退出旧浏览器。** 完全退出使用该副本的浏览器及后台进程，关闭会话自动恢复。在 0.4.0 下停下 Life 等写入入口，核实钱包与身体的在途操作已经排空，再完全退出 DSH。能确认停写和独占访问后才导出。
2. **先备份再换包。** 用获准的适配入口做私有导出，用 0.4.0 创建并校验回退备份，把导出和该备份绑定为同一轮。原副本继续停写，换包后用 v0.5.0 标签的源码执行带备份的离线迁移。
3. **核对后再清理旧数据。** 确认迁移完成，核对原编号、余额、库存和身体状态，在一次性隔离克隆上验证新页面。经主人确认后才清除浏览器里的旧记录。
4. **需要时可回退到 0.4.0。** 放行前保持停写，换回 0.4.0，核验并恢复升级前的备份，再把浏览器旧记录按原值恢复。核对通过后才解除停写，私有导出留到主人关闭回退窗口。

## 隔离验收

在隔离环境的 DSH **Her World → 版本**页更新到 0.5.0，确认插件可以激活。按迁移清单验收钱包后，再试 Room 和桌宠的活动刷新、重复点吃饭和紧凑聊天窗的语音取消。隔离验收通过后再升级日常机器。

## 已知限制

- 0.4.0 已打开的页面仍能改写浏览器里的旧钱包记录。需要能核实旧宿主已排空、能独占读取浏览器来源的适配入口。任一条件无法确认时，停在导出前。
- 关闭多只桌宠时如果切换工作区，已经交给上游处理的那一只仍可能在原工作区完成隐藏并保存显示状态。
- 合并时已通过 Room 语音与刷新、桌宠平台和紧凑聊天窗语音的 Electron 检查。生产 DSH 设置窗和实机 QQ／微信以实机验收结果为准。
